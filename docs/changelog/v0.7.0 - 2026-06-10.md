# v0.7.0 - 2026-06-10

Fuzzy kana search is finally here! And it's even faster than its non-fuzzy counterpart! Searching for hiragana will now also return results that match the corresponding katakana, and vice versa. This should make it much easier to search for words with uncommon kana usage, which quite often happens in manga and light novels.

The second big feature is the so-called "quick-add-list". The quick-add-list makes it very fast to save words you want to review later. Just double tap on the word you want to save, and it will automatically be added or removed from the quick-add-list. You can configure which list you want to use as your quick-add-list in the settings menu. There will be a small blue bookmark icon on the word card to indicate whether the word is already added to the list or not.

Most of the work in this update went into background improvements and optimizations. Here are some of the highlights:

- Total app size went down from ~248MB to ~157MB.
- Search times were cut by ~10% for non-fuzzy J->E searches, and ~50% for E->J searches.
- Exporting and importing archives will stores at most 100 items in memory at once instead of possibly thousands (depending on the size of your history and library lists).
- Library lists handling will not get significantly slower as you add more items to them anymore.

## New features ✨

- 🔥 Fuzzy kana search: searching for hiragana/katakana will now also return results that match the opposite kana type.
  - For example, searching for `あめ` will give you results for both `あめ` and `アメ`.
  - This mode can be toggled on and off in the settings.
  - Using fuzzy search results in roughly 2x search speed.
  - The search will still try to prefer results that match the exact kana type when both variants are present.
- 🔥 Quick-add-list: quickly add items to a preconfigure library list by double tapping on the word in the search results.
  - The quick-add-list can be configured in the settings menu, and can be any of your library lists.
  - Double tapping on a word that is already in the quick-add-list will remove it from the list, so you can easily undo accidental additions.
  - A small blue bookmark icon on the word card will indicate whether the word is already in the quick-add-list or not.
- Progress bars for import and export of archives.
- Dim kanji on words where the word is most commonly written in kana.
- Underline the part of the word results that matched the search term.
  - This can be toggled on and off in the settings, as it can be a bit distracting.
- The language selector under the search bar is working now.

## Changes 🔧

- Rework the archival system
  - Archives are now being streamed in chunks, which should reduce memory usage for large archives, as well as letting the UI show progress for import and export.
  - The internal format of the archive files have been changed, but it should still be possible to import the old archives (although without any meaningful progress bar).
  - The archives will now also preserve the order of your library lists, which was not the case before.

- Rework the (re)initialization system
  - Retain legacy database logic, so that older versions of the database can still be migrated with newer versions of the app
  - Automatic user data backups made before reinitialization will now be picked by future versions of the app in case one version fails.
  - The database will no longer be migrated in-place, instead the database will be completely recreated from scratch and user data will be imported into the database.
    - This should make the process more robust against unforeseen migration bugs and quirks with SQLite's `ALTER` statements.

- Rework the underlying data structure of library lists
  - The old data structure used for library lists was optimized for reordering instead of fast lookups.
  - The new data structure should make lookups much faster, and will be especially noticeable for the following actions:
    - Exporting an archive
    - Adding items to library lists
    - Scrolling through a library list with a lot of items in it.

- Whenever a search only results in a single word, the word will now be automatically expanded to show details.
- When you toggle on the "disable history tracking" mode, the appbar will be colored purple to make it more obvious.
  - It was a bit unfortunate when you suddenly realized that you weren't tracking any history after a whole reading session...
- Display the current versions of the datasources used in the `Settings > Datasources` page.

## Bugfixes 🐞

- Fix a bug where renaming a library list would cause subsequent library lists to disappear.
- Fix font usage in various places, where japanese text could accidentally be rendered with chinese fonts depending on your system settings.
- Fix a bug where exporting archives would leave a lot of temporary files hanging around until the app was restarted.
- Fix a bug where moving off and back to the settings page while exporting/importing archives would cause the UI to not show progress, while the operation was still running in the background.
- Fix a bug where adding new library lists would not update the UI until you moved off and back to the library page.
- Fix a bug where a small subset of the radical search buttons would unexpectedly not result in any search results.

## Other 📝

- Various optimizations for the database, resulting in an overall smaller size.
